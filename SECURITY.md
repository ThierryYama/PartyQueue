# Política de Segurança

## Versões suportadas

Enquanto o PartyQueue estiver antes da versão 1.0, apenas o código mais recente
da branch `main` receberá correções de segurança.

## Relatando uma vulnerabilidade

Não publique detalhes exploráveis em uma issue pública. Use o recurso de
private vulnerability reporting do GitHub quando ele estiver disponível. Caso
contrário, abra uma issue sem detalhes técnicos solicitando contato reservado
com o mantenedor `@ThierryYama`.

Inclua, em canal privado, o impacto observado, os passos mínimos para reproduzir
e possíveis mitigações. O recebimento será confirmado assim que possível, e a
correção será coordenada antes de qualquer divulgação pública.
