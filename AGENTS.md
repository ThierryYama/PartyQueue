## Sobre o projeto
construir um produto de portfólio tecnicamente forte que resolva a pergunta: **“o que o nosso grupo consegue jogar hoje?”**


## Infraestrutura Inicial
- Monorepo

## Stack
- React.js, TypeScript.
- TypeScript, Nest.js
- gerenciador de pacotes: pnpm

## Comandos importantes
- Rodar testes: `Não há testes por hora`
- Lint: `pnpm run lint`
- Build: `pnpm run build`
- Rodar localmente: `pnpm run dev`

## Convenções
- Para branch e commits utilze conventional commits + o nome pr>
- Siga a formatação já atribuida.

## O que NÃO fazer
- não commitar direto na main
- não alterar arquivos de migration já aplicados
